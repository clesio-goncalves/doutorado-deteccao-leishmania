Os mesmos 1.568 recortes convertidos para Lab, com CLAHE no canal L (clipLimit=3.0, tileGridSize=(16, 16)) e salvos como o empilhamento [L, a, b], sem voltar para RGB. A rede recebe os três canais Lab diretamente.

  • Ao abrir as imagens, as cores parecem falsas (núcleos esverdeados). Isso é esperado: o visualizador interpreta L, a, b como R, G, B.
  • Os .txt são idênticos aos de 02_recortes_512/.
  • Resultado: não melhorou a média (mAP50 0,407), mas deu o melhor resultado da série na lâmina leish_3 (0,366).
